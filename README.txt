# Tacoma Plumbing Local SEO Website

This is a static, multi-page Local SEO website template.

## Before publishing
Replace:
- [BUSINESS NAME]
- [PHONE]
- [REAL STREET ADDRESS IF ELIGIBLE]
- [CITY]
- [ZIP]
- example.com URLs
- placeholder image with real business photos
- generic/placeholder review text with genuine review content or remove it
- service-area claims with the business's real service area

## Architecture
- index.html = homepage
- services/ = core service pages
- service-area/ = city/service-area directory
- service-area/*.html = individual local pages
- css/style.css = shared styling
- js/main.js = shared JavaScript
- robots.txt = crawl directives
- sitemap.xml = URL inventory

## Important Local SEO rules
1. A website cannot force a Google Map Pack ranking through code.
2. Do not create fake addresses or fake reviews.
3. Do not claim cities the business does not genuinely serve.
4. Do not mass-produce near-identical doorway pages.
5. Keep NAP and business details consistent with the real business.
6. Add genuine photos and replace the placeholder SVG.
7. Submit the real sitemap in Google Search Console after deployment.
8. Align the website with the real GBP, but do not stuff keywords into the GBP business name.

## Map
The template intentionally does not use the Google Maps JavaScript API, so there is no API-key error.
If a real client needs an interactive map, add it after deployment and secure/restrict the API key.
